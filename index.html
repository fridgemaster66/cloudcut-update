    GitHub — kopia projektów w chmurze

    Projekty zapisują się na tym komputerze. Na GitHuba trafiają te, które zaznaczysz w menu głównym i klikniesz „Zapisz na GitHub”.

    Wystarczy sama nazwa, np. cloudcat-project001 — program dopisze Twoje konto. Jeśli repozytorium nie istnieje, założy je (prywatne).
    Najprościej: jeśli ten komputer jest już zalogowany do GitHuba (przez gita), CloudCut skorzysta z tego logowania — bez kopiowania tokenu.

    albo wklej token:

    YouTube — wysyłanie filmów prosto z CloudCut

    Po połączeniu w oknie Eksportu pojawi się „Wyślij na YouTube”: tytuł, opis, tagi, miniatura, widoczność i „dla dzieci” — bez wchodzenia na stronę YouTube.

    Jak zdobyć Client ID i Client secret (jednorazowo, ok. 5 minut)
    1. Otwórz Google Cloud ↗ i utwórz projekt, np. „CloudCut”.
    2. Włącz YouTube Data API v3 ↗ (przycisk „Włącz”).
    3. W ekranie zgody OAuth ↗ wybierz „Zewnętrzni”, wpisz nazwę i swój e-mail, a w „Odbiorcy” → „Użytkownicy testowi” dodaj swój adres Gmail (ten od kanału).
    4. W Dane logowania ↗ kliknij „Utwórz dane logowania” → „Identyfikator klienta OAuth” → typ „Aplikacja komputerowa” → Utwórz.
    5. Skopiuj Client ID i Client secret, wklej poniżej, kliknij „Zapisz”, a potem „Połącz z YouTube”.

    Google każe takim aplikacjom w trybie testowym łączyć się ponownie co 7 dni, a filmy z projektów bez audytu YouTube publikuje jako prywatne (widoczność zmienisz w YouTube Studio). Adres powrotu dla programu:
